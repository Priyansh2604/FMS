  - Catch httpx.HTTPStatusError 5xx  → error code "LLM_UNAVAILABLE"

KEY DESIGN DECISIONS
================================================================================

  - FastAPI uses service_role key (bypasses RLS) for DB operations
  - Node.js acts purely as API gateway, no business logic
  - user_id passed as query param (auth via Supabase client-side session)
  - OCR: Tesseract via pytesseract + pdf2image
  - LLM: OpenRouter (openai/gpt-4o-mini), provider-abstracted
  - Temp files cleaned in finally block (never leaked)
  - Duplicate detection: unique index on (user_id, merchant, amount, expense_date)
  - Category normalization: exact match → alias map → fuzzy substring → "Other"
  - Confidence: weighted score (OCR 20%, LLM 30%, amount 20%, date 15%, merchant 15%)
